# Changelog

## 0.1 Draft — 2026-10-19

- Reframed the repository as the non-ratified Open Data Product Harness (ODPH) draft.
- Added the human-readable ODPH specification in the existing Slate three-column documentation structure.
- Added canonical YAML JSON Schema, generated JSON Schema, machine-readable object records, full/minimal/standalone examples, validation, and artifact-consistency checks.
- Defined the local-only boundary: no live access, real approval, credential suspension, external dispatch, platform write, or compliance-grade audit claim.

The name, standards-family home, authority semantics, and execution profile contracts remain open questions before ratification.
